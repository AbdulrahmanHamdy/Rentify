Important Decisions:
- Earlier decisions all stand: no generic repository; ownership enforced in Application layer; single global ValidationFilter; GlobalExceptionHandler is the only exception->status mapper; creating a Pending contract Reserves the unit; 404 when the caller can't see a record, 403 when they can see it but can't act; contract+unit share one scoped DbContext/transaction.
- Swagger per-endpoint auth/error docs are generated by one operation filter instead of [ProducesResponseType] on every action, so new controllers get correct docs automatically.
- Swashbuckle pinned to 6.x because 8.x switches to Microsoft.OpenApi 2.x (different OpenApiSecurityScheme/Reference types).
- Swagger is off outside Development unless Swagger:Enabled=true, so production doesn't expose the API surface by accident.
